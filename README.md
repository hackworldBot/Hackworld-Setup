# 🚀 Hackworld Setup

> The Ultimate Debian Workstation Installer

Hackworld Setup est un framework modulaire permettant de transformer une installation Debian fraîche en une station de travail complète pour le développement, la cybersécurité et l'administration système.

## ✨ Fonctionnalités

- Détection automatique du matériel
- Détection de la distribution Linux
- Installation modulaire
- Interface interactive
- Journalisation complète
- Génération de rapports
- Optimisations système
- Support NVIDIA
- Support Docker
- Support Python
- Support Node.js
- Support Android
- Support Virtualisation
- Support IA locale
